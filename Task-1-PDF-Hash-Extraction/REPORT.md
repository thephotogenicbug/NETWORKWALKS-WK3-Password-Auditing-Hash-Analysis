# Task 1 – PDF Hash Extraction Using NetworkWalks Hash Calculator

## Objective
Extract the password hash from an encrypted PDF supplied for the authorised lab exercise.

## Tool
NetworkWalks Hash Calculator.

## Activities
- Opened the NetworkWalks Hash Calculator.
- Selected the encrypted PDF used in the lab.
- Ran the extraction process.
- Reviewed the extracted PDF hash and the displayed format information.

## Observation
The tool completed the extraction and displayed a PDF hash. The page identified the output as compatible with pdf2john / Hashcat workflows. The screenshot is included as supplied.

## Outcome
Successfully extracted a PDF password hash for the password-auditing exercise.
